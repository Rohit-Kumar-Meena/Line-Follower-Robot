# Line Follower Robot 🤖

An Arduino-based autonomous robot that follows a predefined path using IR sensors. 
The project also includes gesture-based manual control, wireless communication, 
and a wheel-driven seed-dropping mechanism.

## ⚙️ Key Features

- Autonomous line following using IR sensors
- Gesture-based manual control using MPU6050
- Wireless communication using NRF modules
- Wheel-driven seed-dropping mechanism
- Arduino-based motor control

## 🔧 Components

- Arduino Uno
- IR Sensors
- BO Motors
- MPU6050
- NRF Modules
- Li-ion Batteries
- Seed-dropping mechanism

## 🛠️ Tools

- Arduino IDE
- Autodesk Fusion 360
- 3D Printing
- Laser Cutting
